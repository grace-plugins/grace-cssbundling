3 Usage

Add dependency to the build.gradle,

repositories {
    mavenCentral()
}

dependencies {
    implementation "org.graceframework.plugins:cssbundling:0.2.0-SNAPSHOT"
}

Then, executing the following command, it will copy the Bootstrap css and javascripts to the app/assets,

$ grace css:install bootstrap
